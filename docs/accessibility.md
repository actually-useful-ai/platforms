# Accessibility Guide

Accessibility is a first-order requirement for every platforms skill.

## Shared expectations
- Keyboard or remote operability
- Visible focus
- Screen-reader semantics where the platform supports them
- Captions/audio description for media
- Reduced motion options
- Readable contrast and reflow

## EPUB
Require language metadata, heading order, alt text, and navigation. Prefer EPUBCheck + Ace.

## TV
Require D-pad paths, Back behavior, and no touch-only primary actions.

## Watches
Prefer glanceable hierarchy and non-color-only status.
