# Platforms KDP Cover

Generate full-wrap cover geometry from trim, bleed, paper, and page count.

## Deliverables
- Cover spec JSON with spine width and barcode reserve
- SVG layout showing front/spine/back and safe zones
- Comparison notes against the current KDP calculator (human confirmation required)

Do not upload covers to KDP automatically.
