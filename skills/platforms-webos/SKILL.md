# Platforms webOS

Package offline web bundles for LG webOS.

## Workflow
- Consume reproducible `www` assets and `appinfo.json`
- Use `ares-package` when available
- Validate focus, Back, screensaver policy, icons, and versions
- Inspect `.ipk` contents before store staging
- Human upload to LG Seller Lounge
